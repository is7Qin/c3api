2. First login: the FIRST registered user automatically becomes platform_admin.
   Register, then sign in at /user/login and administer the gateway at /app.
   Sync pricing after the first boot (POST /api/admin/pricing/sync) — an empty
   price table returns 402.

3. External dependencies: this chart does NOT deploy PostgreSQL or Redis. Point
   it at your own instances via externalDatabase / externalRedis (dsn/addr or an
   existing Secret). Prefer a Redis instance WITHOUT an allkeys-lru eviction
   policy (eviction only forces verification-code re-issue).

4. Persistence & upgrades: the application creates its schema on first start
   (fresh setup only, no migration path). Back up external PostgreSQL before
   upgrading.
