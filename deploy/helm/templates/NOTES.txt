     kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ $fullname }} {{ $svcPort }}:{{ $svcPort }}
   Then open:
     - Console / dashboard:  http://localhost:{{ $svcPort }}/app
     - User console:         http://localhost:{{ $svcPort }}/user
     - Health check:         http://localhost:{{ $svcPort }}/healthz
   {{- if .Values.ingress.enabled }}
   Ingress is enabled; reach the app through the configured hosts. Note that the
   "/" Prefix also exposes /healthz externally.
   {{- end }}

2. First login: the FIRST registered user automatically becomes platform_admin.
   Register, then sign in at /user/login and administer the gateway at /app.
   Sync pricing after the first boot (POST /api/admin/pricing/sync) — an empty
   price table returns 402.

3. External dependencies: this chart does NOT deploy PostgreSQL or Redis. Point
   it at your own instances via externalDatabase / externalRedis (dsn/addr or an
   existing Secret). Prefer a Redis instance WITHOUT an allkeys-lru eviction
   policy (eviction only forces verification-code re-issue).

4. Persistence & upgrades: the app never creates or alters its schema. The
   schema comes from the {{ if .Values.migrations.job.enabled }}pre-install/pre-upgrade migration Job (migrations.job.enabled=true){{ else }}migration step you must run yourself (migrations.job.enabled=false){{ end }}:
   `-migrate up`. Readiness is /readyz; a pod that finds an unusable schema stays
   alive and NotReady instead of crash-looping. Back up external PostgreSQL
   before upgrading. An older database needs a one-time `-migrate adopt
   --snapshot 0001` first (see the chart README).
